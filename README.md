## Kaise Run Karein (How to Run Locally)

### Tareeqa 1: Direct Double Click (Fastest)
1. Is folder me jayen: `C:\Users\cWW\.gemini\antigravity\scratch\stitch_sports`
2. **`run.bat`** file par double click karein.
3. Server start ho jayega aur browser automatically open ho jayega.

### Tareeqa 2: Python Command Line
Terminal ya PowerShell me yeh command chalayein:
```powershell
python C:\Users\cWW\.gemini\antigravity\scratch\stitch_sports\server.py
```
Phir browser me open karein: [http://localhost:3000](http://localhost:3000)

### Tareeqa 3: Node / npm
```powershell
cd C:\Users\cWW\.gemini\antigravity\scratch\stitch_sports
npm start
```

### Tareeqa 4: Direct File Open (Baghair Server ke)
Aap direct `index.html` par double click karke kisi bhi browser (Chrome, Edge) me open kar sakte hain.
